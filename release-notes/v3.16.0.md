## v3.16.0 の主な変更（v3.7.1 から）

### 新機能
- **不要ファイルの削除**（新ステップ 2）：広告・宣伝のファイルや 10MB 以下のファイルなど、作品と関係ないものを見分けて削除。オンの間は、ほかの作業（名前の整理・仕分け・フォルダ名・重複比較）の対象から外す
- **フォルダ一覧**：Finder / エクスプローラーのように閲覧・操作
  - リスト / サムネイル / タイル表示、全展開・全格納、マウスを乗せるとサムネイルを大きく表示
  - 名前の変更、ドラッグ＆ドロップでの移動、新規フォルダ、ゴミ箱へ、右クリックメニュー
  - 好きなフォルダを最上位にして表示（例：My Pack だけを表示）
  - タイル表示ではフォルダごとに見出しを付けて並べ、ダブルクリックで中身へ移動、「一覧へ戻る」で一番上へ
- **再生**：プレビューの中・プレーヤー画面・全画面で再生。PikPak の変換画質（HLS）にも対応
  - 外部プレーヤーで開ける：macOS は IINA・Infuse、Windows は PotPlayer。GOM Player・VLC などは .m3u またはリンクのコピーで
- **英語表示**：ブラウザの言語に合わせて日本語 / 英語を自動で切り替え（左下の 🌐 で手動切り替えも可）
- **左側のメニュー**と、新しい読み込み画面
- キー操作を OS（macOS / Windows / Linux）に合わせて自動で切り替え
- 重複の**強制削除**：全件にチェックが入っている組（広告ファイル同士など）も、確認画面で選べば削除できる

### 修正・改善
- フォルダ名が広告ファイルの名前（例：AI女友）に変わってしまう問題を修正
- `X/X/ファイル` のように同じ名前で入れ子になったフォルダを、片付けステップでまとめるように。仕分けで入れ子を作らないように修正
- ログイン期限が近いときに、再読み込みを繰り返して止まる問題を修正
- 自動で回復できる認証エラーは、エラー件数に数えないように変更
- 本編を誤って消さないよう、品番のない大きなファイルは「要確認」に回すように変更

詳しい変更点は [CHANGELOG.md](https://github.com/Noel-Labs39/pikpak-distill/blob/main/CHANGELOG.md) を参照してください。
