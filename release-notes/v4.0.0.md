## PikPak Distill – Dedupe v4.0.0（プレビュー版）

3.x で積み上げてきた機能をまとめた、最初のプレビュー版です。

### 主な機能
- **整理の 8 ステップ**：読み込む → 不要ファイルを削除 → ファイル名を整える → 作品ごとに仕分け → フォルダ名を揃える → 重複を比べて削除 → (1)を外す・片付け → 販売者ごとに仕分け
- **販売者ごとに仕分け**：fd2ppv.cc・fc2cmadb.com で販売者を調べ、`販売者別/販売者名（ID）/` へまとめる。入れ子・別の販売者の混在も見直す
- **フォルダ一覧**：検索・移動・名前の変更・ドラッグ・新規フォルダ
- **再生・コマ一覧**：その場で再生、コマを並べて見比べ・画像で保存
- **リンク・マグネットを追加**／**解凍**（パスワードを記録して自動で試す）
- **左メニュー**：クラウドDL・最近の追加・再生履歴・スター・ゴミ箱
- **PikPak で同期**：調査結果・判断・設定を PikPak に保存し、ほかのブラウザや Mac アプリと共有
- **新しい版のお知らせ**

### Mac アプリ版
下の `Dedupe-macOS.zip` を展開して、`Dedupe.app` をアプリケーションフォルダに入れてください。Apple の公証を受けていないため、初回は「システム設定」→「プライバシーとセキュリティ」→「このまま開く」が必要です（詳しくは README）。
