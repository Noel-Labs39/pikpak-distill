## v4.0.0 の主な変更（画面の一新）

v3.17.0 で行った画面の一新を、区切りとして 4.0.0 で公開します。v3.17.0 と機能は同じです。

### 画面
- 画面右上に、契約容量のメーター・テーマ（ライト / ダーク / 自動）・表示言語・**設定**・閉じる（×）を集約
- **設定パネル**（右からスライド）：表示 / 再生 / 整理 / 情報（バージョン・更新履歴・ログ）
- 左のアイコン列は「整理 / フォルダ一覧 / 再読み込み」の 3 つに整理。バージョンの表示はヘッダーの 1 か所だけに
- 右下の **Distill** メニューは「フォルダ一覧」「Dedupe スキャン」の 2 つに。エラーがあるときだけ件数と「確認」を表示
- 状態の表示を画面の下に移動

### フォルダ一覧
- パスを常に「ホーム › …」から表示し、↑ で読み込んだ場所より上の階層へも移動できるように。まだ読み込んでいないフォルダは「未スキャン」と表示し、開いたときに中身だけ読み込む
- 読み込んだ場所の外へも、ドラッグや「移動…」で移動できる（読み込んだ場所そのものとその上のフォルダは、誤操作防止のため移動・ゴミ箱の対象外）
- 「表示中のフォルダ内の割合」の列と、下の欄に契約容量に対する割合を表示
- 選択中の操作（再生・名前の変更・移動・最上位に・ゴミ箱）は、項目を選んだときだけ青い帯で表示

詳しい変更点は [CHANGELOG.md](https://github.com/Noel-Labs39/pikpak-distill/blob/main/CHANGELOG.md) を参照してください。
